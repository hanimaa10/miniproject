HEARTDISEASE VS LIFESTYLE
This project focuses on analyzing the relationship between lifestyle factors and the occurrence of heart disease using a cleaned and integrated patient dataset. The dataset is transformed using techniques like one-hot encoding, normalization, and feature engineering to prepare it for analysis. Through data visualization and statistical exploration, the project identifies lifestyle behaviors that are strongly associated with heart disease. The findings aim to provide actionable insights for healthcare professionals and individuals, supporting preventive healthcare strategies and promoting healthier lifestyles
